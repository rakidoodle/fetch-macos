Fetch Help

Your downloads, at home on your Mac.

Add your first download

  1. Choose New Download or press ⌘N.
  2. Paste a direct HTTP/HTTPS file link, YouTube video URL, or magnet link. For torrent files, choose Torrent and Choose Torrent File.
  3. For YouTube, choose Video or Audio only. Resolution and format are independent. Resolution caps quality at the selected height.
  4. Choose Add Download. Progress, transfer speed and estimated remaining time update in your library.

Control transfers

Use the pause/play control in a row. Right-click a transfer for pause, resume, retry, cancel, file actions and history removal. The Downloads menu can pause all transfers or resume paused downloads.

Cancel retains partial files so retry can recover them. Remove from History also keeps downloaded files on disk. Finder manages permanent deletion.

Quitting pauses unfinished downloads and saves history. Reopen Fetch and resume the downloads you want to continue. Closing the window keeps Fetch running; use ⌘Q to quit.

Find and save your files

Completed files live in ~/Downloads/Fetch, in a folder for each transfer. Use Show in Finder to reveal the result, or Save a Copy to copy a finished file elsewhere. Torrent downloads can contain several files; find each file in the inspector.

Search names and source URLs with ⌘F. Sidebar categories filter your library. The toolbar filter menu controls sorting and status filters. Open details with the info button.

Settings and appearance

Open Fetch → Settings with ⌘,. Connections range from 1–16, active downloads from 1–8, and the optional speed limit uses KiB/s. Zero means unlimited. Connection changes apply to new transfers; global speed changes affect file and torrent transfers immediately and new YouTube transfers.

Fetch follows your Mac's Light, Dark or Auto appearance and system accent color. Native controls support keyboard navigation. Reduced-motion settings apply to system animations.

If a download fails

The row and inspector show the engine's error. Check the URL, network connection, free storage and folder permissions, then Retry. Some hosts block automation or require authentication; credential links and unsupported URL schemes are rejected. YouTube availability and quality depend on the source.

If the service disconnects, choose Restart Service. Settings shows engine readiness. Launch errors include a button to open service logs at ~/Library/Application Support/Fetch/logs. App settings and history are saved in the same Application Support folder.

Privacy and support

Fetch runs on your Mac. Its authenticated service listens only on localhost. Downloads contact their source hosts, YouTube and torrent peers. Torrent traffic can upload pieces to peers while receiving data; completed transfers do not keep seeding.
